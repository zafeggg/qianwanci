| 前端接入 TM 合约地址/ABI | ✅ | 已接入：`services/token.js`（最小 ERC20 ABI，只读查 `balanceOf`、签名调 `transfer`）+ 资产页充值弹窗**真实读取链上余额**。合约地址/精度/确认数由后端 `GET /api/deposit/info` 下发，前端不硬编码；**主网地址仍需 owner 提供**（私链地址已够联调）。验证 `scripts/verify-deposit.mjs` PASS=16/0 |
| DApp 充值入口 | ✅ | 资产页新增「充值」按钮 + 弹窗：展示收款地址（可复制）、代币合约、确认数、链上余额，并支持一键 `transfer` 充值。⚠ 顺带修了一个**资金归属缺陷**：原监听对**收款地址**入账，而 DApp 给所有用户展示同一个池地址 → 所有用户的充值都会记到池主账户（实测两笔 25 TM 确实记错）。新增 `Chain.DepositCreditTo`（`recipient` 默认 / `sender` 共享池口径），私链设为 `sender` |
| FIBO 主网 TM 合约地址 | 🟡 | 前端/后端都已按"从配置读"实现，但 **FIBONACCI 主网的 TM 合约地址尚未确定**（需 owner 给出部署地址与初始发行量），换地址只需改配置、不用改代码 |
